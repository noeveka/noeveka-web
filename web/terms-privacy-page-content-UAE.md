# APPENDIX: COOKIE BANNER BRIEF FOR HARSH (do not publish this section)

**Library:** `vanilla-cookieconsent` v3 (orestbida/cookieconsent). Free, MIT licensed, framework agnostic, works fine with a Vite build. `npm install vanilla-cookieconsent`.

**Categories:**
- **Necessary** (always on, cannot be turned off): Cloudflare security and delivery cookies.
- **Analytics** (off by default): Google Analytics 4.

**Behaviour:**
- Show the banner on first visit, before GA4 loads.
- GA4's script must not fire until the visitor accepts the Analytics category. Use Google's Consent Mode pattern (set `analytics_storage` to `denied` by default, update to `granted` only `onConsent`/`onChange` when Analytics is accepted) rather than just hiding the banner after any click, since the two are not the same thing.
- Buttons: "Accept All", "Reject All", "Manage Preferences". No pre-ticked boxes.
- Store the visitor's choice for 6 months (the library's default), after which the banner reappears.
- Add a small "Manage cookie preferences" link in the site footer, next to the Privacy Policy and Terms links, that reopens the banner so a visitor can change their mind later.

**Suggested banner copy:**

> **Heading:** We use cookies
> **Body:** We use cookies to understand how visitors use this site. Necessary cookies keep the site secure and working. Analytics cookies are only set if you accept them.
> **Buttons:** Accept All · Reject All · Manage Preferences
> **Link:** See our [Privacy Policy]

**Preferences panel copy:**

> **Necessary** (always on): Required for the site to function securely. Cannot be turned off.
> **Analytics**: Helps us understand how visitors use the site, using Google Analytics 4. Off unless you turn it on.
